# РАЗЛОМ — мир на грани

Глобальная стратегия в реальном времени: 205 стран, экономика, армии и фронт, ПВО, дипломатия, сетевая игра до 8 игроков (поиск игр через интернет).

## Скачать — [последний релиз](../../releases/latest)
- **Windows:** `RAZLOM-Setup-….exe`. Игра обновляется сама.
  Если Windows предупредит «Неизвестный издатель», нажмите «Подробнее», затем «Выполнить в любом случае».
- **Mac с чипом M1–M4:** `RAZLOM-…-mac-arm64.dmg`. **Mac с Intel:** `RAZLOM-…-mac-x64.dmg`.
  Перетащите РАЗЛОМ в «Программы». Первый запуск — правой кнопкой → «Открыть» (или «Настройки → Конфиденциальность и безопасность → Всё равно открыть»).
  Новые версии на Mac скачиваются отсюда же.
