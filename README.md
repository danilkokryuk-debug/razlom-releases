# РАЗЛОМ — мир на грани

Глобальная стратегия в реальном времени: 205 стран, экономика, армия, дипломатия и сетевая игра до 8 игроков.

**Скачать:** откройте [последний релиз](../../releases/latest) и скачайте `RAZLOM-Setup-….exe`.
Игра обновляется сама: при запуске она проверяет новую версию и ставит её, когда вы выходите из игры.

Windows может предупредить «Неизвестный издатель». Нажмите «Подробнее», затем «Выполнить в любом случае».
